Description

A short Game Jam game following one of the two themes: Hidden
I used Unity 6 and wrote in C#,
Made art using Aesprite, and used online sound generators to make any sound effects. Music was done by importing a song made through the game Offbeat which I had creative lincense for (The game and devs allow all songs made using Offbeat to be used for whatever purpose its really cool)
Game uses static, rotating, and moving enemies with a dynamic mesh to represent L.O.S
The player has to move around precisely and activate switches to make it to the end of the level.

Retro

The game was pretty fun to work on but hard when I had a few hours after work to work on it.
The FOV effect uses a procedually made mesh which updates base on if it hits an object tagged wall or not. The update goes by raycasting from the forwards direction then rotating a set angular amount before doing it again. If there isnt a hit, the next vertext of the mesh is at the max distance of the raycast. If the raycast hit a wall the point is at the collision point between the raycast and the wall.
Making the mesh move was slightly difficult mainly as if mesh is rotated the FoV becomes unstable as it is still trying to use the original starting spot. Moving had a similar problem with not moving but that was due to forgetting to set the origin to the current position.
The rest of my code was simple as it was reused ideas. Interacting with levers were done by having a raycast around the player detecting any interaction objects. These objects stored data within them and were apart of a Interactable Object base class which. Once detected if the player presses the interact button it tells the closes interactable object (done as to handle multiple interactable objects in close proximity) to run its interaction code which does whatever effect is wanted, in this case open and close a linked door.
